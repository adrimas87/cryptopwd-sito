Funzioni

Tutto quello che serve.
Niente di quello che non serve.

Pensato per chi gestisce le password di sé, della famiglia e dell'azienda, ed è stanco di affidarle a un server sconosciuto.

Cifrato sul dispositivo

Le password vengono cifrate con AES-256 prima di essere salvate o inviate. La chiave nasce dalla tua password principale e resta solo in memoria: quando l'app si blocca, sparisce.

Sul tuo Google Drive

L'archivio cifrato vive nel tuo spazio. Nessun server nostro, nessun abbonamento. L'app vede solo i file che ha creato lei, non il resto del tuo Drive.

Sincronizzazione intelligente

Le modifiche fatte offline su più dispositivi vengono unite voce per voce. Le eliminazioni si propagano.

Funziona offline

Una copia cifrata resta su ogni dispositivo: le password si leggono anche in aereo o senza campo.

Modalità riservata

Per il desktop remoto o lo schermo condiviso: dati coperti, visibili solo tenendo premuto. Doppio Esc blocca tutto.

Soggetti e categorie

Tu, i familiari, la tua azienda: ognuno con le sue categorie (Banca, Email, PEC…). Filtri istantanei.

Generatore robusto

Password casuali e lunghe con un tocco, generate dal motore crittografico del dispositivo.

Appunti a tempo

Copi la password e dopo 30 secondi gli appunti si svuotano da soli. Blocco automatico per inattività.

I tuoi dati restano portabili

Importa da Chrome, Firefox, Bitwarden e da qualsiasi file CSV. Esporta in ogni momento un backup cifrato. Nessuna gabbia: se un giorno vorrai andare altrove, porti tutto con te.

Sicurezza

Progettato perché nessuno possa leggerle.
Neanche noi.

CryptoPwd non ha un server che custodisce i tuoi dati. Google, l'hosting dell'app e chiunque altro vedono solo blocchi di dati illeggibili.

  • Content-Security-Policy restrittiva: la pagina non carica codice da terze parti.
  • Nessuna libreria esterna: solo le API crittografiche native del browser.
  • Manomissioni rilevate: la cifratura autenticata rifiuta dati alterati.
  • Accesso minimo a Drive: lo scope drive.file vede solo il file dell'app.

La password principale non è recuperabile. È il prezzo della vera riservatezza: nessuno ha una copia della tua chiave. Scrivila su carta e conservala in un luogo sicuro.

Domande frequenti

Le risposte, in chiaro.

CryptoPwd può vedere le mie password?

No. Le password vengono cifrate sul tuo dispositivo con una chiave derivata dalla tua password principale, che non lascia mai il dispositivo. Noi non abbiamo server che ricevono i tuoi dati e Google conserva solo un file illeggibile.

Cosa succede se dimentico la password principale?

I dati non sono recuperabili, da nessuno. È una scelta di progetto: se esistesse un modo per recuperarla, esisterebbe anche un modo per rubarla. Conserva la password principale in un luogo sicuro.

Perché serve Google Drive?

Per sincronizzare i dispositivi senza un server intermedio. L'app usa il permesso più ristretto possibile (drive.file): può vedere e modificare solo il file che ha creato, non i tuoi documenti, le foto o gli altri file.

Posso usarlo senza Google Drive?

Sì. Puoi tenere l'archivio solo sul dispositivo ed esportare manualmente un backup cifrato. Perdi la sincronizzazione automatica tra dispositivi.

Funziona senza connessione?

Sì. Ogni dispositivo mantiene una copia cifrata locale. Le modifiche fatte offline vengono sincronizzate e unite appena torna la rete.

Quanto costa?

CryptoPwd è gratuito. Lo spazio occupato su Google Drive è minimo: pochi kilobyte anche con centinaia di password.

Posso importare le password che ho già?

Sì, da un file CSV esportato da Chrome, Firefox, Bitwarden e dalla maggior parte dei gestori di password. Ricordati di eliminare il file CSV dopo l'importazione: contiene le password in chiaro.
