3. Il Servizio

CryptoPwd è un gestore di password che funziona nel browser e può essere installato come app (PWA). Le password vengono cifrate sul dispositivo dell'utente e, se l'utente lo sceglie, sincronizzate tramite il suo account Google Drive. Il fornitore non gestisce server che conservino i dati degli utenti.

Il Servizio è offerto gratuitamente. Il fornitore può aggiungere, modificare o rimuovere funzioni, sospendere o interrompere il Servizio, dandone se possibile un preavviso ragionevole sul sito. Poiché l'archivio è conservato sul dispositivo e sul Drive dell'utente, anche in caso di interruzione l'utente mantiene il proprio file cifrato e può esportarne un backup.

4. Requisiti

  • Per usare il Servizio devi avere almeno 14 anni; se sei minorenne, con il consenso di chi esercita la responsabilità genitoriale.
  • Serve un browser aggiornato con supporto a WebCrypto e IndexedDB.
  • Per la sincronizzazione serve un account Google, il cui uso è regolato dai Termini di servizio di Google.

5. Le tue responsabilità

  • Password principale. Sei l'unico a conoscerla. Non è memorizzata né recuperabile dal fornitore. Se la dimentichi, i dati cifrati non potranno essere decifrati da nessuno.
  • Backup. Ti raccomandiamo di esportare periodicamente un backup cifrato (Impostazioni → Esporta backup cifrato) e di conservarlo in un luogo sicuro.
  • Sicurezza dei dispositivi. Sei responsabile della sicurezza dei dispositivi e dell'account Google che usi con il Servizio. Un dispositivo compromesso (ad esempio da malware o da un programma che registra i tasti) può esporre i dati mentre l'app è sbloccata.
  • Uso lecito. Usa il Servizio solo per conservare credenziali di cui hai diritto di disporre e nel rispetto della legge.
  • File importati. I file CSV importati contengono password in chiaro: eliminali dopo l'importazione.
